# Snapshot

This directory is a copy of [bounty-economics](https://github.com/KhomDev/bounty-economics) so viability-gate can carry the ledger schema and the tier and clause taxonomies `vg import` writes against. The source repository was not modified.

`vg import` writes a ledger in the shape of [schemas/ledger.schema.json](schemas/ledger.schema.json). Clause classes come from [data/clause-classes.yaml](data/clause-classes.yaml). Tier shapes come from [data/tier-shapes.yaml](data/tier-shapes.yaml).
