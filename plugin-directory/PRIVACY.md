# Privacy policy

The priorart Anthropic Directory plugin (the `plugin-directory/` tree in
[KhomDev/priorart](https://github.com/KhomDev/priorart)) does not
collect, store or send any data.

It ships a skill and read-only commands. It does not run the priorart
CLI, does not open a network connection, and has no hooks or installer. There
is no telemetry and no account.

Claude Code may read files in your project when you ask it to, using only
Read, Grep, Glob and LS. Those reads stay in your local session. They are not
sent to the plugin author.

If you run `priorart` yourself, that process is yours. This plugin does not
start that program and does not receive its output.

Questions: [github.com/KhomDev/priorart/issues](https://github.com/KhomDev/priorart/issues).
